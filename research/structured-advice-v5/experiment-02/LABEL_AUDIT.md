# Label audit before training and predictions

Same-author AI review against the unchanged v5 policy. This is not independent human adjudication.

## Repair data

64 explicit new notes target failure families observed in experiment-01, plus replay of the previous 132 training notes. The old test statements were not copied into fresh qualification. Lesson/module/lecture completion inside a course is progress; all modules/the entire course is complete. Past read/watched alone retains a null action and a missing_action reason. Known requests and opinions retain their actions while unnamed works carry missing_identity. Independent actions are MIXED/mixed; unresolved it/that does not invent a media subject.

## Prospective synthetic qualification

48 new notes, all eleven categories, new fictional work titles rather than relying on world knowledge. Exact uniqueness is checked against current training and the old qualification notes. Semantic task families intentionally overlap repair families; no semantic or pretraining independence claim. Nine partial-series/course controls explicitly test whole-work completion mistakes. Expected labels frozen before predictions and unchanged afterward.

## Public diagnostic

24 nominations retained in deterministic source rank order, not selected based on predictions. Prior exact expressions/IDs screened using 662 existing project artifacts. Sixteen scored mappings: explicit music requests, explicit book/novel opinions/ratings, and nonmedia booking/dining plans. Eight queries marked ambiguous/unscored before inference because the medium is not explicit enough or the requested type is an essay/chronicle outside the literal book/novel policy. They remain in generation and contract-validity evaluation, and all outputs must be reported. No replacement query was drawn to increase accuracy or fill scored quotas.

Original source intent/slot annotations are retained as provenance, but never model input and never sufficient alone to force an OpenMemory gold label. Fictional personal notes, cloud-authored transcriptions and private memories are not substituted for the original public wording. Source queries are evaluation-only, absent from train.json.

## Qualification

Freeze all prediction/scoring code and labels. Compare base, previous v5 candidate and repair candidate on identical notes and prompt. Require no synthetic/series/uncertainty/public scored regression versus previous v5; improvement over base on synthetic full correctness; zero partial-course/series false completion; zero contract-invalid responses across all 72, including unscored public rows. Passing does not qualify a release by itself. No repeated tuning on this test set.
